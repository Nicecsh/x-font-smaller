# X.com 字体改小

让 X（x.com）网页版在手机浏览器里字体变小的篡改猴脚本。

## 背景

X 新版在手机 Edge 里字体太大，X 自带的设置和 Edge 设置里都没有调字号的地方。这个脚本把 x.com 整体缩小到 0.95 显示，刚好合适。

另外，头像菜单中的个人资料、呼叫、Premium、列表等菜单项使用 14.5 px 字号，行高为原来的一半。

## 安装

1. 在浏览器里安装 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/)（手机 Edge：菜单 → 扩展里搜索安装）。
2. 打开下面的安装链接，篡改猴会弹出安装确认，点「安装」：

   https://github.com/Nicecsh/x-font-smaller/raw/main/x-font-smaller.user.js

3. 刷新 x.com 即可。

## 调整大小

默认缩小到 0.95。在篡改猴里打开这个脚本，把 `SCALE` 那行的 `0.95` 改成别的数字（越小字越小，比如 0.9；只想小一点点就改成 0.98），保存后刷新页面生效。

在脚本里修改 `MENU_FONT_SIZE` 可设置头像菜单字号，单位为 px。修改 `ROW_RATIO` 可调整菜单行高，例如 `0.5` 表示原行高的一半，`0.6` 表示原行高的 60%。

## 说明

- 只在 `x.com` 和 `twitter.com` 生效。
- 整页缩放与头像菜单的字号、行高可分别调整。
